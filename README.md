# SIGMAI
### Secure GIS-AI Interface

SIGMAI is a local, secure and auditable QGIS plugin that allows AI agents and developer tools to interact with QGIS through structured, validated commands.

Repository: https://github.com/LuanCortesM/SIGMAI
Issues: https://github.com/LuanCortesM/SIGMAI/issues

## Main Goals

- Operate QGIS through a local bridge bound to `127.0.0.1`.
- Use bearer-token session authentication and local session discovery.
- Expose safe, auditable JSON commands instead of uncontrolled UI automation.
- Support cartography, layout export, layer inspection, CRS checks, vector tools, raster tools, workflows, plugin diagnostics and controlled development workflows.
- Keep normal operation safe by default. Developer Mode is explicit, local, warning-protected and disabled by default.

## Manual Installation in QGIS

1. Download or build `dist/sigmai.zip`.
2. Open QGIS.
3. Go to `Plugins > Manage and Install Plugins > Install from ZIP`.
4. Select `sigmai.zip`.
5. Enable `SIGMAI`.
6. Open the SIGMAI panel and start the local bridge when needed.

The ZIP must contain a single root folder named `sigmai/`, with `metadata.txt`, `__init__.py`, `LICENSE`, `plugin.py` and the required modules inside it.

## Basic Use

SIGMAI runs inside QGIS. AI clients or local scripts can connect to the local bridge using a session token shown by the plugin.

Typical safe workflow:

1. Start the bridge in the SIGMAI panel.
2. Query `status`.
3. Query `get_capabilities`.
4. Inspect layers and CRS.
5. Run dry-run commands when available.
6. Execute safe commands with explicit parameters.
7. Generate maps, reports or diagnostics.

## Security Model

- Localhost only: `127.0.0.1`.
- Bearer token required.
- Pairing code is not a token.
- Normal mode does not expose unrestricted Python execution.
- Developer Mode requires explicit activation in the QGIS UI and typed confirmation.
- Dangerous actions require confirmation where applicable.
- Existing outputs are not overwritten unless `confirm_overwrite=true`.
- Logs and reports must not expose full tokens, passwords or credentials.

## Dependencies

SIGMAI is a Python QGIS plugin. It is designed to run with the Python and libraries shipped with QGIS/OSGeo4W. Some optional workflows depend on QGIS Processing providers or third-party QGIS plugins installed by the user; those integrations should remain allowlisted and audited.

## Compatibility

- Minimum QGIS version: 3.28.
- Recommended: current QGIS 3.x LTR or newer.
- Python: the Python runtime bundled with QGIS.

`Created with SIGMAI/QGIS.`
