# QGIS Workflow Report

Use this skill after a multi-step QGIS workflow.

## Report Contents

- User request.
- Commands planned.
- Commands executed.
- Dry-run results.
- Confirmations received.
- Files created.
- Layers used.
- CRS assumptions verified.
- Errors and warnings.
- Recommended next steps.

## Rules

- Do not report a step as completed if it only ran as dry-run.
- Include `request_id` values when available.
