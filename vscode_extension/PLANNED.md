# Planned VS Code Extension

Planned features:

- Side panel connection manager.
- Token entry and connection status.
- Layer and CRS inspector.
- Capabilities browser grouped by command taxonomy.
- Environment snapshot viewer.
- Bridge log viewer.
- Recent errors panel.
- QGIS plugin validator.
- Plugin packager.
- JSON command editor.
- Workflow templates for common GIS tasks.
- Developer Mode panel:
  - list installed plugins;
  - inspect plugin structure;
  - validate `metadata.txt`;
  - collect logs;
  - prepare publication checklist.
- User Cartography Mode panel:
  - choose layers;
  - inspect CRS;
  - dry-run map workflow;
  - export layout.
- GitHub/Codex integration hooks for bug reports and pull requests.
