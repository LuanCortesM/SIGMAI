# SIGMAI Map Authorship Policy

SIGMAI separates plugin authorship from authorship of maps and other products generated by users.

## Plugin Authorship

The SIGMAI plugin is authored by MACIEL, L. S. C. and this credit belongs in plugin metadata, README files, About screens, institutional documentation, release notes and plugin technical reports.

## Generated Map Authorship

Maps, reports, layouts and data products generated with SIGMAI belong to the user or organization that produced them.

Generated maps should use the first available value from:

- `map_author` supplied in the command;
- the configured SIGMAI user profile;
- QGIS project metadata;
- a neutral software credit line.

If no map author is provided, public layouts should use a neutral line such as:

```text
Elaborado com SIGMAI - Secure GIS-AI Interface/QGIS.
```

SIGMAI must not automatically use the plugin author as the map author in public mode.

## Development Mode

Development and test mode may use the plugin author as a temporary fallback only when the test explicitly enables that behavior or the user explicitly supplies that name as `map_author`.

## Required Credits

Professional map layouts should distinguish:

- map author;
- data source;
- organization, when supplied;
- CRS/datum;
- creation date;
- software credit;
- plugin author only in technical/plugin reports.
