# North Arrow And Scale Rules

## North Arrow

Use a north arrow when:

- the map is rotated;
- the map is used as a standalone final product;
- the map lacks grid/graticule orientation;
- the template is topographic or official-style.

North arrow is optional when:

- the map is north-up;
- grid/graticule is visible;
- the map is a small inset;
- the map is a presentation terrain plate where orientation is not part of the question.

Rules:

- keep it small and subordinate;
- avoid decorative excess;
- do not place it over important map content;
- for topographic sheets, prefer formal orientation/declination treatment;
- for environmental maps, a simple clean arrow is enough.

## Scale

Use a scale bar when:

- distance interpretation matters;
- trails, buffers, areas or accessibility are discussed;
- output is intended for report/publication.

Use numeric scale only when:

- final print size is known;
- layout is fixed;
- CRS/projection is appropriate.

Never silently use degrees as professional metric scale.

If CRS is geographic:

- warn explicitly;
- prefer projected CRS for metric analysis;
- avoid claiming precise distances.

For Cruzeiro/SP environmental/trail products, prefer:

`SIRGAS 2000 / UTM zone 23S`.
