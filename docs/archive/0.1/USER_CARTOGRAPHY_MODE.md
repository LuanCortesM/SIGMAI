# SIGMAI User Cartography Mode

## Plugin Authorship Vs Generated Map Authorship

SIGMAI credits MACIEL, L. S. C. as the plugin author in plugin metadata and documentation.

Maps generated by users should credit the map author supplied in the command or user profile. If no author is supplied, the footer should use a neutral software credit instead of assigning authorship to the plugin developer.

## Level 5 Consolidated Behavior

SIGMAI can now generate visible basic cartographic maps with CRS-safe extents, title, legend, scale, north indication and source/authorship. The default legend can be filtered with `legend_layers` so only relevant layers appear.

## Level 6 User-Facing Additions

Agents can inspect and query vector data before map generation:

- inspect fields with `list_fields`;
- sample attributes with `sample_features`;
- validate filters with `validate_expression`;
- query matching features with `query_features`;
- dry-run selections and extractions before creating outputs;
- control layer visibility and ordering for cleaner maps.

SIGMAI - Secure GIS-AI Interface is the public name of the project.

User Cartography Mode is for non-specialist users who ask for maps and spatial analysis in natural language.

The agent translates intent into safe commands.

## Current GIS Automation Rule

Agents should call `diagnose_crs` before metric analysis and use `dry_run=true` before write commands such as `buffer`, `clip`, `dissolve`, `fix_geometries`, `reproject_layer`, and `export_layer`.

## Required Agent Behavior

- Inspect project and layers first.
- Check CRS before spatial analysis.
- Prefer temporary outputs until the user confirms a file path.
- Use dry-run before modifying the project.
- Explain the map workflow in plain language after execution.
## Phase 2.1 Cartography Commands

SIGMAI can now compose a basic cartographic layout through atomic commands:

- `add_layout_map`
- `set_layout_extent`
- `add_layout_label`
- `add_layout_legend`
- `add_layout_scale_bar`
- `add_layout_north_arrow`
- `set_layer_style`
- `generate_basic_map`
- `generate_workflow_report`

`create_layout` alone is not considered a complete map. A complete basic map requires a map item, valid extent, readable layer style, title, legend, scale bar, north indication, source/credits and an exported output.

AI agents should use `generate_basic_map` for normal users and use the atomic commands when a map needs to be debugged or assembled step by step.
