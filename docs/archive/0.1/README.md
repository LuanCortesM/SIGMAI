# Documents of the 0.1 and 0.2 series (May–September 2026)

These documents were written for SIGMAI 0.1 — before the MCP server, the consent layer, the cartographic engine and the rulebook existed — and, for `ROADMAP_0.2.md`, during the 0.2 series. They are kept for the history of the project and **do not describe the current software**: command names, map scoring, plugin-management flows and file locations have changed since. `MAP_VISUAL_SCORING_RULES.md`, for instance, documents the 0.1 evaluator that the rulebook replaced (see [CARTOGRAPHIC_QUALITY_MODEL.md](../../CARTOGRAPHIC_QUALITY_MODEL.md)).

For the current documentation, start at [docs/README.md](../../README.md).
