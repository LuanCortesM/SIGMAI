about=SIGMAI lets AI assistants operate QGIS through a local, auditable command interface instead of screen automation. It ships a standards-compliant MCP server (JSON-RPC 2.0 over stdio) so Claude, Cursor, Codex and any other MCP client can connect; a consent layer where the user chooses between read-only, ask-every-time and allow-for-this-session, with output-folder sandboxing, per-session limits and an audit trail; and a cartographic engine that composes page-aware map layouts, fits the extent to the map frame, rounds the scale to the cartographic series, sizes the scale bar, computes the coordinate grid interval, builds a legend covering every visible layer, and then audits the result against an explicit rulebook whose findings tell the assistant what is wrong and how to fix it. A chat panel inside QGIS talks to a model with your own API key (Anthropic, or any OpenAI-compatible provider, including a local Ollama model); the model's only tools are SIGMAI's. When you use the chat, the conversation and what the tools return (layer and field names, counts, sample attribute values, file paths, audit reports and, if enabled, a map preview) are sent to the AI provider you configure; data files are not. The key is kept in the encrypted QGIS authentication database. The bridge binds to 127.0.0.1 only and requires a bearer token. Normal operation never exposes arbitrary Python execution; Developer Mode is explicit, warning-protected and disabled by default. SIGMAI runs on the Python bundled with QGIS/OSGeo4W. Developed by Luan da Silva Cortes Maciel as a research product associated with Herpeto Mantiqueira.
