about=SIGMAI lets AI assistants operate QGIS through a local, auditable command interface instead of screen automation. It ships a standards-compliant MCP server (JSON-RPC 2.0 over stdio) so Claude, Cursor, Codex and any other MCP client can connect; a consent layer where the user chooses between read-only, ask-every-time and allow-for-this-session, with output-folder sandboxing, per-session limits and an audit trail; and a cartographic engine that composes page-aware map layouts, fits the extent to the map frame, rounds the scale to the cartographic series, sizes the scale bar, computes the coordinate grid interval, builds a legend covering every visible layer, and then audits the result against an explicit rulebook whose findings tell the assistant what is wrong and how to fix it. The bridge binds to 127.0.0.1 only and requires a bearer token. Normal operation never exposes arbitrary Python execution; Developer Mode is explicit, warning-protected and disabled by default. SIGMAI runs on the Python bundled with QGIS/OSGeo4W. Developed by Luan da Silva Cortes Maciel as a research product associated with Herpeto Mantiqueira.

    1.1.2
    - Licença: MIT em todo o projeto (o GitHub já declarava MIT; o plugin ainda dizia GPL-3.0-or-later). Texto integral na raiz e no pacote.
    - Fundamentos das regras corrigidos: duas regras citavam normas ABNT que não dizem o que lhes era atribuído (NBR 6027 é sumário; NBR 13133 é levantamento topográfico) e oito citavam "convenção" ou "boas práticas" sem fonte. Agora cada regra cita o Decreto 89.817/1984 (Normas Técnicas da Cartografia Nacional, arts. 12 a 21), a Resolução IBGE PR 1/2015, IBGE (1999), Brewer (2016), Slocum et al. (2009), Snyder (1987), Machado et al. (2009), Robertson (1977), Okabe & Ito (2008), PLOS ONE ou Rodriguésia — ou declara que o número é decisão de projeto do SIGMAI; a API do QGIS aparece como verificação, não como fundamento. Teste garante.
    - Análise de sensibilidade dos limiares (tools/threshold_sensitivity.py): 138 mapas re-pontuados variando cada limiar do regulamento e as decisões do compositor recalculadas; registro em docs/experiments/2026-09-19_sensibilidade_limiares/. Os limiares do compositor viraram constantes nomeadas (LAYOUT_SWITCH_GAIN, MAX_EFFECTIVE_MARGIN_PERCENT, FONT_SCALE_EXPONENT).
    - sigmai_cartographic_rulebook expõe o limiar de ΔE real (lia 15,0 fixo), a cobertura mínima do inserto e a procedência dos limiares.

    0.2.0
    - Real MCP server (JSON-RPC 2.0 over stdio). The previous transport was a custom JSON-lines loop that no MCP client could speak, so Claude Desktop, Cursor and Codex never connected.
    - AI actions can now execute. Write commands were previously forced to dry-run, so no map could ever be produced. A consent layer replaces that: read-only by default, ask-every-time, or allow-for-this-session, with output-folder sandboxing, per-session limits and an audit trail.
    - New cartographic engine: page-aware layouts from A5 to A0 in either orientation, extent fitted to the map frame, scale rounded to the cartographic series, scale bar sized to the frame, coordinate grid with a computed interval, legend covering every visible layer, and a real north arrow symbol linked to grid north.
    - New cartographic rulebook and audit: 26 explicit rules, each with its rationale, reference and the command that fixes it. The old evaluator only checked whether items existed and graded a defective map as "A - Professional map".
    - Redesigned panel: dockable, three-step connection flow, ready-to-paste client configuration, connection self-test, access control and activity log. Token hidden by default and stable across QGIS sessions.
    - Fixed: fixed port 8765 with no fallback; token regenerated on every QGIS start; blocked-token scan rejecting legitimate payloads (a field named "code", the PythonConsole plugin, expressions); plugin version hardcoded in four places; raw instead of normalised command executed; coordinate grid enabled with interval zero and reported as created.
