about=SIGMAI is a secure local bridge between AI agents and QGIS. It exposes validated JSON commands, bearer-token authentication, session discovery, permissions, dry-run support where applicable, audit logs, cartographic map generation, layer/project inspection, vector/raster tools, workflow foundations and plugin diagnostics. The bridge is local-only and binds to 127.0.0.1. Normal mode does not expose unrestricted Python execution. Developer Mode is explicit, warning-protected, disabled by default and intended for QGIS plugin development. SIGMAI is designed to use the Python and libraries bundled with QGIS/OSGeo4W; optional workflows may require QGIS Processing providers or user-installed plugins. Developed by Luan da Silva Cortes Maciel (MACIEL, L. S. C.) as a research product associated with Herpeto Mantiqueira.
